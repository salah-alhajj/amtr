## 1. عائلة أزرار التطبيق
تم استبدال أزرار Flutter التقليدية بنظام أزرار أبل عالي الاستجابة:
1. **`AppPrimaryButton`:** يدعم التدرج الزمردي/الأزرق، مع مؤشر تحميل مدمج، وحركة تصغير ناعمة أثناء الضغط عبر `AnimationController` منضبط.
2. **`AppSecondaryButton`:** زر بنمط خفيف (Tinted) بلون هادئ وخلفية شبه شفافة (10% Alpha).
3. **`AppOutlinedButton`:** زر محدد بدقة مصرفية ناعمة.
4. **`AppIconButton`:** زر دائري مريح للأصابع مع مساحة لمس آمنة (44x44pt).
