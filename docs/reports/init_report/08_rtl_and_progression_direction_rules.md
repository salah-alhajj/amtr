## 1. القواعد الجوهرية للغة العربية واتجاه النص
في بيئة العمل العربية (RTL):
1. **اتجاه القراءة والتدفق:** يبدأ من اليمين وينتهي في اليسار.
2. **حركة التقدم والانتقال للأمام (Forward Progression):** تشير حصرياً نحو اليسار (`←`). السهم المتجه نحو اليمين (`→`) يعتبر في الأنظمة العربية عودة للوراء (Backwards) ويحظر استخدامه للتقدم.
3. **أمان الجداول المحاسبية:** حظر استخدام أحرف الرسم الصندوقية ASCII/Unicode (مثل ┌, ─, ┐, │, ├) لأنها تتفتت وتنهار تماماً في محركات التصيير ثنائية الاتجاه (BiDi)، واستبدالها حصرياً بجداول Markdown القياسية أو HTML الدلالية `<table dir="rtl">`.

### 2. عائلة Chevrons المخصصة:
تم استبدال أيقونات الانتقال الافتراضية بـ `ForwardChevron` التي تفحص اتجاه اللغة تلقائياً وتعرض سهم اليسار في النمط العربي:
```dart
class ForwardChevron extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Icon(
      Icons.arrow_back_ios_new_rounded, // سهم يشير لليسار في واجهة RTL
      size: 14,
      color: context.textTertiary,
    );
  }
}
```
