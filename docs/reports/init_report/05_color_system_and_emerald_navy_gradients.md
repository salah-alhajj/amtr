## 1. هندسة الألوان وتناغم الأخضر والأزرق
تنفيذاً للشرط الأول في المحادثات: *"استخدم الاخضر والازرق بشكل اساسي والالوان المتدرجة بينهما"*:
تم ابتكار لوحة ألوان محاسبية سيادية تعتمد على:
1. **الأزرق الملكي (Apple Primary Blue - `0xFF007AFF` / `0xFF0A84FF`):** يمثل الثقة، القيادة، والرسوخ المؤسسي.
2. **الأخضر الزمردي (Emerald Green - `0xFF34C759` / `0xFF30D158`):** يمثل التدفق المالي الإيجابي، الأرباح، والنمو.
3. **التدرجات المتداخلة (Emerald-Navy Gradients):** استخدام تدرجات تبدأ من الأخضر الزمردي الفاتح وتنتهي بالأزرق السماوي الهادئ في بطاقات ملخصات الأرباح وفواتير الشحنات.

```dart
static const Color primaryBlue = Color(0xFF007AFF);
static const Color deepNavy = Color(0xFF0F172A);
static const Color primaryGreen = Color(0xFF34C759);
static const Color emeraldTeal = Color(0xFF10B981);
```

| اللون | الاستخدام في الواجهة | الدلالة النفسية والمالية |
| :--- | :--- | :--- |
| Primary Blue | أزرار الإجراءات، الترويسات الرئيسية، أيقونات التصفح | الثقة والاستقرار المحاسبي |
| Primary Green | المبالغ المحصلة، صافي الربح، مؤشرات السداد التام | الازدهار والسيولة المالية |
| Status Danger | الديون المتأخرة، المبالغ السالبة، إجراءات الحذف | التحذير والحرص المصرفي |
