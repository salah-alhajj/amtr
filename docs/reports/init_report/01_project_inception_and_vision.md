## 1. الملخص التنفيذي والسياق العام
انطلقت فكرة تطبيق **amtr** لتلبية متطلبات إدارة سلاسل الإمداد، الشحنات المجمعة، والطلبات الفردية لرجال الأعمال والتجار، مع التركيز على دقة المحاسبة المالية المتعددة العملات، وبناء بنية برمجية محلية الصمود (Offline-First) تعتمد على قاعدة بيانات محلية SQLite لا تحتاج إلى خوادم وسيطة أو اتصال دائم بالإنترنت.

منذ الرسالة الأولى للمستخدم، تم الاتفاق الحازم على عدة ركائز استراتيجية:
1. **المعمارية النظيفة (Clean Architecture):** الفصل الصارم بين طبقات الكيان وقواعد البزنس (Domain)، طبقة البيانات والمصادر (Data)، وطبقة واجهات العرض (Presentation).
2. **لغة التصميم الراقية (Apple HIG Style):** تبني مبادئ شركة أبل في البساطة البصرية، الزوايا المنحنية فائقة النعومة (Continuous Curvature)، وتأثيرات الزجاج الشفاف الخفيف (Glassmorphism)، والتدرجات الانسيابية الهادئة.
3. **السيادة المالية والمصرفية:** دعم ثلاث عملات رئيسية (الريال اليمني YER، الريال السعودي ﷼، الدولار الأمريكي $)، وتطبيق أدق معايير الحسابات المحاسبية المصرفية، واستخدام الرمز الرسمي المعتمد من البنك المركزي للريال السعودي `﷼`.
4. **الاستقلالية التقنية والاعتماد على الذات:** حظر مولدات الكود (`build_runner`)، ورفض الاعتماد على خطوط جوجل عبر الشبكة (Google Fonts)، واعتماد خط محلي خالص (IBM Plex Sans Arabic).

| الركن الاستراتيجي | المتطلب الأساسي | آلية التنفيذ المعتمدة |
| :--- | :--- | :--- |
| المعمارية | Clean Architecture ثلاثية الطبقات | مجلدات منفصلة لكل فيتشر (domain, data, presentation) |
| إدارة الحالة | Pure Dart BLoC | كود يدوي نقي دون أي Annotations أو Build Runner |
| واجهات المستخدم | Apple HIG & Fluid Micro-interactions | بطاقات وحقول وأزرار مخصصة مستوحاة من iOS |
| اللغات والاتجاه | RTL كامل ودعم اللغتين | flutter_localizations + .i18n() JSON engine |
| التخزين المحلي | Local SQLite Database | sqflite مع إمكانية التصدير والاستيراد الخام و JSON |
